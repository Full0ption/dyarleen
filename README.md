# ديار لين — DYARLEEN

كتالوج مشروع **ديار لين** السكني في المنيا الجديدة، من **ليناس للتطوير العقاري**.

- الموقع: المنيا الجديدة — منطقة الامتداد، المجاورة الخامسة، قطعة ٣٢٤ A، خلف جامعة اللوتس، على الطريق الصحراوي الشرقي.
- المبنى: أرضي + ٤ أدوار، وحدتين في كل دور — ١٠ وحدات فقط.
- المساحات المتاحة: ١٣٠ و١٣٥ م² (الدور المتكرر)، بتراسين لكل وحدة.
- التسليم: بعد سنة.
